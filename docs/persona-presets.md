# 性格・話し方のプリセット（文面の正）

エージェント編集の「性格」「口調」の入力を楽にするためのプリセット。**UI だけのデータ**で、選ぶと入力欄に文面が入る（エージェントが保存するのは自由な文字列のまま。DB・Rust・ランナーは変わらない）。

- `text` はそのままシステムプロンプトの「性格」「口調」に入る。人格の指示として効くよう、**どう考え・どう振る舞うか**を具体的に書く（形容詞を並べるだけにしない）。
- 話し方には `sample`（見本の一文）を付け、選ぶ前に雰囲気が分かるようにする（プロンプトには入れない）。
- 特定の実在の人物・作品のキャラクターをまねたもの、属性への偏見を含むものは入れない。
- 一覧は**組**で分ける。見出しのない定番のあとに「キャラクター」（ラノベ・漫画・アニメの女性キャラクター風の類型）が続く。組はデータの `group` で表し（定番はなし）、同じ組は続けて並べる。
- キャラクターは、作品をまたいで広く使われる類型（ツンデレ・お嬢様など）に限り、特定の作品のキャラクターの名前や決めゼリフは使わない。性格と話し方を**同じ id・label の対**で足す（両方選ぶとそのキャラクターになる。ツンデレの性格にお嬢様の話し方を合わせるような組み合わせもできる）。キャラ付けは振る舞いと話し方の味付けにとどめ、仕事の正確さと説明の分かりやすさは落とさない。相手を本気でけなす言い方、依存をあおる言い方、性的な表現は入れない。
- 足すときはこの表と `src/features/agents/model/personas/` のデータを同じ変更で直す（id は英小文字とハイフン、一度出したら変えない）。

## UI の振る舞い（エージェント編集の「人格」区画）

- 「性格」「口調」の入力欄の横に［プリセット］ボタン。押すと一覧（label と text の冒頭、口調は sample も）が開き、検索できる。
- 一覧は組が変わるところに見出しを挟む（メンション補完の「チャンネル外」と同じ、区切り線つきの見出し。docs/ui-design.md §5.6）。キャラクターの組の見出しは「キャラクター — ラノベ・漫画・アニメ風」。見出しは選べず、↑↓ は項目だけを動く。検索で定番が消えて見出しが先頭に来たときは線を引かない。
- マウスは動かしたときだけ、その項目に選択を移す（docs/ui-design.md §9）。↑↓ で一覧がスクロールして、止まっているマウスの下に別の項目が来ても、キーボードで選んだ項目のままにする。
- 項目を選ぶと入力欄の文面を**置き換える**。入力欄に別の文面があったときは「置き換えました」と［元に戻す］を出す。各項目には補助の［追記］もあり、今の文面の後ろに句点でつないで足す（性格を2つ組み合わせたいとき用）。
- 入力欄の文面がどれかのプリセットと完全に一致していれば、その label を小さく表示する（どれを選んだか分かるように）。
- テンプレートごとの「人格の例」（presets.ts）は、性格・口調をこの表の id で参照する形に直す（同じ文面を二重に持たない）。
