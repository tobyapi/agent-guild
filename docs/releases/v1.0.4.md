# AIギルド v1.0.4

Claude のエージェントは、最大ターン数が空欄なら、これまでの30ターンを超えて作業を続けられます。上限を設定してそこに達した場合は、途中までの返事と停止理由を表示します。作業は手動で止められます。1回の実行時間は最長30分です。

アプリが更新を確認するタイミングを、各言語の README とコード署名ポリシーで訂正しました。起動時、アプリに戻ったとき、再接続したときと、5分ごとに確認します。繁体字版のチャンネル統計では、トークン数の表記を「Token」にそろえました。

英語版と日本語版の README で、役割ごとの権限やチャットの書式、開発時の検証手順の説明を読みやすくしました。
