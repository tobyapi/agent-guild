# AIギルド v1.0.0

既存のギルドを使っている方は、更新前のアプリの版を確認してください。**v0.1.28 をお使いの場合は、そのまま更新できます。** それより前の版をお使いの場合は、先に v0.1.28 で同じデータフォルダを一度開き、終了してから v1.0.0 へ更新してください。先に v1.0.0 へ更新してしまっても、v0.1.28 を経由する必要があるデータは変更されず、案内画面から v0.1.28 を入手できます。[v0.1.28 の配布ページ](https://github.com/tobyapi/agent-guild/releases/tag/v0.1.28)

## 初回起動とバックアップ

v1.0.0 では DB の後方互換性を終了し、保存形式を刷新しました。初回起動時に旧 DB のコピーを作り、内容を照合してから新形式に一度だけ変換します。会話、メンバー、添付の記録、通知済みの記録、中断したジョブを引き継ぎます。

変換直前の DB は、使用中のデータフォルダ内の `backups/pre-1.0.0/<UTC日時>-<UUID>/guild.db` に残ります。添付・画像・エージェントの作業ファイルは引き続き元の場所を使います。これらも含めて退避するときは、アプリを終了してデータフォルダ全体をコピーしてください。

変換が完了しなかった場合は、復旧画面から再試行できます。旧版の配布ページ、ログの場所、作成済みの場合はバックアップの場所も画面に表示します。

## 変換後に v0.1.28 へ戻す手順

旧版用バックアップから戻せるのは変換直前の状態までです。v1 で追加した発言は旧版用バックアップに含まれません。`guild.db` だけを上書きすると、残った v1 の WAL ファイル（`guild.db-wal`）の内容が旧版の DB に混ざり、DB が壊れるおそれがあります。

1. v1.0.0 を終了します。
2. データフォルダにある `guild.db`・`guild.db-wal`・`guild.db-shm` を、別の空のフォルダに移して保管します。ファイルは削除しないでください。見当たらないファイルは飛ばしてかまいません。
3. データフォルダ内の `backups/pre-1.0.0/<UTC日時>-<UUID>/guild.db` を、データフォルダの直下にコピーします。
4. v0.1.28 を入れ直し、同じデータフォルダを開きます。

## 外観と履歴の変更

- 設定画面から「背景の動き」を削除しました。現在の v3 形式の生成テーマは引き続き選択・復元できます。
- 旧テーマのプレビュー、背景 Recipe・定型背景用の処理、古い外観設定キーの読み替えを削除しました。
- 旧 SVG 枠の生成処理を削除しました。保存済みの枠は変換時に検査して表示します。修復できない SVG 枠を選んでいた場合は「枠なし」に戻します。
- 発言を表示するたびに本文からスキル使用申告を読み直す処理を削除しました。投稿時に記録した使用履歴を表示します。

## 検証範囲

Windows で実データのコピーを変換し、新しい19表の全列と添付ファイルの内容を照合しました。作業段階で未確認の項目は、macOS 実機での移行、両 OS の署名済み配布物を使った自動更新、物理的な電源断、ディスク容量不足時の復旧です。
