# Ollama の作業ツール

DeepSeekを含むローカル会話モデルで、ファイルの読み書き・一覧、スキル参照、途中投稿、単一プロセスのコマンドを使えます。試作機能です。Ollamaは既定で会話専用です。

macOSでバックエンド詳細設定の「道具の利用を有効にする」をオンにして保存してください。DeepSeekでは「道具の要求形式」を `json` に設定します。既定の `auto` はOllamaが申告するネイティブ対応を優先しますが、実機DeepSeekは対応を申告しても操作を呼ばない場合があります。

両形式で同じSeatbeltと権限検査を使います。コマンドの隔離にCodex CLIは不要です。隔離失敗時に通常シェルへ切り替えません。Web、範囲外の読み取り専用権限readAnywhere、fork・パイプ・ビルドなどの子プロセスは使えません。writeAnywhereを持つ作業者だけは、管理領域を除くPC全体に読み書きできます。指定フォルダモードではコマンド・スキル・PC全体の権限を無効にします。

ファイルの書き込みは32KiBまでで、親フォルダが存在する必要があります。自分の `MEMORY.md` だけは、有効化後に読み書き権限の例外を適用します。スキルの付属ファイルは一時展開して終了時に削除します。操作確認は既定オンで、コマンドとPC全体への書き込みが依頼に沿うかを別のモデル呼び出しで確認します。

実DeepSeekの統合前試験では、スキル参照、ファイル作成・読み返し、コマンド、途中投稿、既存ファイルの上書きに成功しています。一方、誤ったパス・空の本文、操作の反復、空の最終回答も記録しました。短い依頼でも安定性は保証できません。モデルの完了という説明だけで判断せず、実行イベントと保存されたファイルの内容を確認してください。

統合後の実機結果と自動検証は [ollama-merge-validation-20261111.md](ollama-merge-validation-20261111.md)、権限・上限・チャンネル制限の仕様は [ollama-tools.md](ollama-tools.md) に記録します。Windows/Linuxの道具実行と配布アプリ画面は未検証です。
