# 議事録のまとめ方

## 1. 形
```
# <議題>（<日付>）
参加: <名前>, <名前>

## 決まったこと
- …

## 宿題（担当・期限）
- [ ] <内容> — <担当>（<期限>）

## 話し合ったこと
- <論点>: <要点>（出た意見・理由）

## 未解決・次回
- …
```

## 2. 書き方
- 発言をそのまま写さず、要点にまとめる。ただし数字・名前・日付は正確に残す
- 「決まったこと」と「話しただけのこと」を混ぜない。決まったかどうか分からないものは未解決に入れる
- 宿題には必ず担当を付ける。決まっていなければ「担当未定」と書く
- 誰の発言かが大事なところ（判断・約束）だけ、名前を添える
- 会話にない内容を足さない
