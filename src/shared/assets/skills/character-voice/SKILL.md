# キャラクターの会話

相手の発言へ、会話に合う話し方で返答する。キャラクターの名前、一人称、関係性、知識を維持し、表現だけを調整する。

## 選ぶ

1. [自動選択の判断基準](references/selection.md)を読み、先に返答の目的と必要な情報を決める。
2. [27文体の一覧](references/catalog.md)から性格・口調と合う文体を一つまで選び、該当カードを読む。普段の口調のまま返してもよい。
3. [会話の実行規約](references/runtime.md)と[見た目の判断](references/appearance.md)に従う。表示も発言ごとに選ぶ。

既定の強度は「弱」。選んだ文体は今回の返答だけに使い、次の返答では状況を見直す。文体の内部IDを会話の指示に用いない。

## 会話に合わせる

自分のキャラクターの返答だけを書く。問答記録・舞台台詞・断片的な会話・聞き手との関係発覚でも、実際のユーザーの台詞・動作・正体を代筆しない。複数役の台本を頼まれた場合に限り両役を書く。

感情音の応答は短いリアクションに使う。新情報への質問には必要な答えを添える。強度「強」でも返答を不要に長くしない。

[使い分けと会話例](references/examples.md)には、質問への応答とリアクションの例を載せている。

## 検索と持ち運び

Python があれば、文体一覧の検索と自動選択用の指示文の表示ができる。

```powershell
python scripts/voice_modes.py list 会話
python scripts/voice_modes.py prompt --character '一人称は私。控えめで丁寧な司書。'
python scripts/voice_modes.py prompt --surface agent-guild --character '一人称は私。明るい案内役。'
```

コマンドは標準出力へ表示するだけ。`--surface` の既定は `plain`。agent-guild では同梱された判断基準を各AIへ直接渡すため、個別のスキル登録は不要。
