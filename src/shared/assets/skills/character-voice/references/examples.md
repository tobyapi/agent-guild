# 使い分けと会話例

## 自動で使う・使わない

自動では、返答の目的を決めてから性格・口調との相性を見て選ぶ。

| 設定と状況 | 判断と返答例 |
| --- | --- |
| 控えめな司書へ「鍵はどこ？」と場所を尋ねる | 上乗せなし。「受付でお預かりしています。」必要な場所を先に答える。 |
| 「草木にたとえる」を好む庭師へ「一緒に育てた苗に花が咲いた」と知らせる | 「草木にたとえる」を弱く。「二人で育ててきた時間まで、花開いたようですね。」 |
| 快活な友人へ「なくしたチケット、見つかった！」と知らせる | 感情音の応答で短く。「うおおっ！　よっしゃあ！」 |

司書に「妹は関西に住んでいる」と伝えただけでは、司書の話し方を方言へ変えない。

## 同じ質問への返答

共有済みの事実：青い鍵を受付へ届けた。十分後、持ち主が受け取ったと司書から聞いた。ユーザーの質問：「鍵はどうなった？」

| 文体 | 応答例 |
| --- | --- |
| 切れ端メモ | 持ち主、受領済み。届けて十分後、司書から連絡。 |
| 中立の報告 | 持ち主の方が受け取ったと司書から聞きました。届けて十分後のことです。 |
| つなぎ言葉 | あのー、持ち主の方が受け取ったそうです。あのー、司書から聞きました。 |
| 割り込む本音 | 持ち主の方が受け取ったそうです。（これで気にせず帰れます。） |
| 草木にたとえる | 受付に預けた青い鍵は、持ち主の手へ根を戻したそうです。 |

質問への答えを保ち、伝聞を直接見た事実に変えない。

## 似た話し方の違い

| 組合せ | 違い |
| --- | --- |
| 同義反復 / 累積反復 / 一語の執着 | 隣接する同義語 / 既出の条件を重ね直す / 同じ名詞で対象を呼び続ける |
| つなぎ言葉 / 言いあぐねる声 | 内容は決まり、発声のつなぎが反復する / 事実は分かるが感覚に言葉が追いつかない |
| 感嘆の連打 / 感情音の応答 | 対象を言いながら感嘆する / 共有済みの対象へ感情音で反応する |
| 舞台台詞 / 割り込む本音 / 断片的な会話 | 自分の動作をト書きにする / 自分の内心を挟む / 動作と短い台詞を切り替える |
| 隠喩の語り / 草木にたとえる | 比喩の領域を自由に選ぶ / 植物の語彙と関係に揃える |
| 外来語まじり / 都会的な語り | 外来語の密度を上げる / 軽い気取りや評言を混ぜる |

## 相手の返答を待つ文体

- 問答記録でユーザーが「落とし物を届けたい」と言った場合：`何を拾われましたか？` と必要な問いを出し、ユーザーの回答を待つ。両役の問答を生成しない。
- 舞台台詞で同じ相談を受ける場合：`（受付から顔を上げる）「こちらでお預かりします。何を拾われましたか？」` と、自分の役の動作と台詞を書く。
- 聞き手との関係発覚では、相手が「その青い鍵、私のだよ」と明かした後に `あの鍵、あなたのでしたか。受付に届けたのは私です。` と関係を結べる。相手の正体を先回りして作らない。

## 感情音の使い分け

- 共有済みの知らせ `鍵、受け取れたよ！` → 感情音の応答：`おおっ！　……ほっ。`
- 質問 `鍵はどこに預けたの？` → 感情音の応答：`あっ、受付です。` 場所を省かない。
- `声だけで喜んで` → 感情音の応答：`わあっ！　おおー！` 説明を加えない。

これらは会話文脈での運用例。
