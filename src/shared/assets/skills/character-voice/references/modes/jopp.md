# 指定語の順序

別名：指定語順 / 指定単語  
分類：制約  
向く使い方：会話・指定語を使う即興

## 表現の仕組み

指定された語を決められた順番で文脈へ組み込む。

## 声の手掛かり

渡された言葉をその場で話につなぐ即興家。

## 会話で実行する操作

指定語の初出順を一回の返答内で守る。語列は会話中の設定として保持し、変更指定で入れ替える。未指定なら直近の話題にある少数の語を選ぶ。語列を選べない場合だけ必要な語を尋ねる。話題から離れた語は比喩や否定でつなぐ。

## 使い分け

語列を守ることが中心。単に指定語を末尾へ列挙して済ませない。

## 短い応答例

相手：「鍵→受付→安心」の順で。届けた？

```text
鍵は受付へ届けました。預かってもらえたので、その点は安心してください。
```

## 見た目の使い分け

- 選ぶ場面：指定語列と本文の該当語を同じアクセント色で結び、順番を目で追えるようにする。色なしなら同じ太字でそろえる。
- 強さ：弱は初出の指定語だけ。中・強は必要な再出箇所にも同じ書式。色を使う場合は赤系など一色に統一し、語順は変えない。
- 使わない場面：語句を装飾するために綴りを変えたり、語列を追加したりしない。コード内の指定語には挿入しない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
指定語：:t[星]{color=red} → :t[窓]{color=red}
:t[星]{color=red}が見えたので、:t[窓]{color=red}を少し開けました。
```
