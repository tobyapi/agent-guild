# 感情音の応答

別名：感情音だけ / 反応の声  
分類：音  
向く使い方：会話・短いリアクション

## 表現の仕組み

間投詞だけを並べ、共有済みの出来事を感情の変化で呼び起こす。

## 声の手掛かり

語彙による説明より先に、反応が声になる人物。

## 会話で実行する操作

共有済みの知らせへ間投詞で応じ、声の変化で気づき・戸惑い・納得・安堵などを表す。新情報への質問には答えの文を添え、反応部分を感情音にする。「声だけ」の指定では感情音だけにする。

## 使い分け

感嘆の連打は物や動作も言う。こちらの中心は間投詞による短い応答。

## 短い応答例

相手：鍵、ちゃんと受け取れたよ！

```text
おおっ！　……ほっ。
```

## 見た目の使い分け

- 選ぶ場面：短い感情音を句読点と空白で並べ、音の切替と間を見せる。一言だけなら通常文字でも成立する。
- 強さ：弱は無装飾。中・強で複数の反応の間を見せるなら layout{rotate=0}。声量差がある場合だけ一音を1.2〜1.3倍にできる。
- 使わない場面：感情音を常に巨大化しない。相手が答えを求める質問では、必要な答えを読める普通の文で添える。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
:::layout{rotate=0}
えっ！　ああ……
　ほっ。
:::
```
