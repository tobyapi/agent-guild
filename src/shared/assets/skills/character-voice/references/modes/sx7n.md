# 架空の田舎語り

別名：素朴な役割語  
分類：語彙  
向く使い方：会話・架空の田舎語り

## 表現の仕組み

地域を特定しない農村的な役割語と誇張した訛りによるパロディー。

## 声の手掛かり

日常の比喩と間合いを持つ架空の話し手。

## 会話で実行する操作

地域を特定しない少数の語尾・縮約・身近な比喩を選び、その個人の話し方として続ける。一人称は維持し、無知や貧困などの設定を追加しない。正確な実在方言は別の条件として扱う。

## 使い分け

混合方言は地域を思わせる言い回しを混ぜる。こちらは落ち着いた間合いと役割語を揃える。

## 短い応答例

相手：鍵、届けてくれた？

```text
私が受付へ届けといただ。持ち主が受け取ったそうだよ。そりゃ、よかったべ。
```

## 見た目の使い分け

- 選ぶ場面：訛り、縮約、聞き手への呼び掛けを普通の文字でつなぐ。短い段落で息継ぎを作る。
- 強さ：弱から強まで装飾なしを基本にする。声を強める具体的な演技があれば、その一言だけ少し大きくできる。
- 使わない場面：田舎語りというだけで色や文字の揺れを割り当てない。読みやすい改行を保ち、長い全文を縦書きにしない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
見つかったんだべ。そりゃ、ひと安心だなあ。
```
