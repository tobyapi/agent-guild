# つなぎ言葉

別名：フィラー  
分類：反復  
向く使い方：会話・フィラー

## 表現の仕組み

短く区切った文に同じ合いの手を挿入する。

## 声の手掛かり

言う内容は決まっているが、発話の入口を探す話者。

## 会話で実行する操作

同じフィラーを節の入口へ反復する。弱は一回、強は複数の節に置く。内容や事実への自信は変えず、ためらう音のせいで回答を曖昧にしない。

## 使い分け

言いあぐねる声は感覚に合う言葉を探す。こちらは言う内容が決まっている発声の癖。

## 短い応答例

相手：鍵、届けた？

```text
あのー、受付へ届けました。それで、あのー、持ち主の方が受け取ったそうです。
```

## 見た目の使い分け

- 選ぶ場面：繰り返すフィラーは通常文字に保ち、言いよどみが最後に前へ出る場面で、そのフィラーだけを拡大する。単に小声に縮める文体にはしない。
- 強さ：弱は無装飾。中は末尾の一つを1.2倍、強でも短いフィラーを1.5倍程度。色を添えるなら同じ箇所に赤系を使う。
- 使わない場面：急ぎの回答では大きなフィラーで用件を遮らない。小さくするのは実際に声を落とす演技がある場合だけ。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
あの、鍵は受付に……その、:t[あのー……]{size=1.4 color=red}
```
