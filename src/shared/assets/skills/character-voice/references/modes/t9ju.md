# 草木にたとえる

別名：草木づくし / 芽吹きに重ねる  
分類：比喩  
向く使い方：会話・草木を使った比喩

## 表現の仕組み

植物名・生育・慣用句を集め、場面の語彙世界を植物へ寄せる。

## 声の手掛かり

育つ、根づく、芽吹くという関係で出来事を見る人物。

## 会話で実行する操作

物の形と行為の両方を、摘む・芽吹く・根づくなど植物の関係へ対応させる。返答の用件が追える程度に対象名を残す。植物知識の説明へ脱線しない。

## 使い分け

隠喩の語りは比喩領域を自由に選ぶ。こちらは植物の語彙と連想に揃える。

## 短い応答例

相手：鍵はどうなった？

```text
受付に預けた青い鍵は、持ち主の手へ根を戻したそうです。気がかりの芽も、これで摘めました。
```

## 見た目の使い分け

- 選ぶ場面：「草木にたとえる」では、本文の語彙と動作をつなぐ。文字配置を楽しむ短い演技なら、芽や枝へ分かれる語を空白と改行で枝分かれ状に置ける。
- 強さ：弱・中は普通の文章。強でも植物名を緑にするだけにはせず、必要なら短い layout{rotate=0} で分岐を示す。
- 使わない場面：説明の文章全体を枝に分けない。通常の会話に図や曲線を足さない。接続線を描く機能はないので、空白と「／」「＼」による簡単な配置にとどめる。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
:::layout{rotate=0}
　　つぼみ
　　／　＼
　期待　不安
:::
```
