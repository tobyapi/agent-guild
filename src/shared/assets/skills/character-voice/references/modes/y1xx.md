# 感嘆の連打

別名：感嘆実況 / 反応の連打  
分類：態度  
向く使い方：会話・短い感嘆

## 表現の仕組み

短い観察と感嘆を次々に打ち出し、興奮の推移を表す。

## 声の手掛かり

見た瞬間に声が出る実況者。

## 会話で実行する操作

相手の知らせや目の前の対象へ短い句で反応する。気づきから次の反応へ動かし、記号を増やすだけにしない。未確認の出来事は足さない。

## 使い分け

感情音の応答は感情音が中心。こちらは物や動作の名前も言う。

## 短い応答例

相手：鍵、受け取れたよ！

```text
あっ、受け取れたんですね！　あの青い鍵！　よかった！
```

## 見た目の使い分け

- 選ぶ場面：感嘆の中から飛び出す短い声を選んで拡大する。色を添えるならその感嘆だけに赤系のアクセントを使う。
- 強さ：弱は一つの感嘆を1.15〜1.3倍。中・強は一〜二箇所の大小差で発見から喜びへの変化を示し、最大1.6倍程度。
- 使わない場面：事実説明や相手の困り事まで大声にしない。すべての感嘆符・全文を同じ大きさで塗らない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
:t[あっ！]{size=1.3 color=red} 見つかったんですね。よかった！
```
