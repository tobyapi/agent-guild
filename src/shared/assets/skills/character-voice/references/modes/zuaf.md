# 同義反復

別名：重ね言い  
分類：反復  
向く使い方：会話・念押し

## 表現の仕組み

近い意味の語を対にして過剰に重ねる。

## 声の手掛かり

言い足して念を押す話者。ひとつの行動に二つの呼び名を与える。

## 会話で実行する操作

同じ意味の語を隣接させ、ひとつの返答で言い足す。弱は短い一組、強は複数の句で持続させる。言い換えで新事実を足さない。

## 使い分け

累積反復は説明済みの条件を積み、同一語の反復は同じ名詞を繰り返す。こちらは近い意味の語を隣り合わせる。

## 短い応答例

相手：鍵、届けてくれた？

```text
はい、受付へ届けて引き渡しました。持ち主本人が受け取って引き取ったそうです。
```

## 見た目の使い分け

- 選ぶ場面：同じ意味を言い直す二語の並びで二重感を出す。通常は無装飾。言葉遊びを見せるときだけ二語を同じ太さにする。
- 強さ：弱は普通の文字。中・強で必要なら同義の一組を weight=bold。二語を重ねて読めなくしない。
- 使わない場面：単なる了承や真剣な念押しでは巨大化・反転を使わない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
無事に、何事もなく、鍵は持ち主へ戻りました。
```
