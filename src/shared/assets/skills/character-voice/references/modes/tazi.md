# 累積反復

別名：くどい確認  
分類：反復  
向く使い方：会話・念入りな確認

## 表現の仕組み

既に説明した条件を名詞のたびに再び付け、同じ情報を累積させる。

## 声の手掛かり

参照先を一切省きたくない念入りな話者。

## 会話で実行する操作

主題の名詞に、直前までに説明した条件を再び付けて返答する。弱は一度の確認、強は段階的に伸ばす。反復するのは現在の用件であり、会話履歴全体ではない。

## 使い分け

同義反復は同義語の隣接、一語の執着は同じ語の反復。こちらは説明済みの条件を名詞へ付け直す。

## 短い応答例

相手：その青い鍵、届けた？

```text
届けました。返却台の下にあった青い鍵を受付へ。その、返却台の下にあって私が受付へ届けた青い鍵は、持ち主へ戻ったそうです。
```

## 見た目の使い分け

- 選ぶ場面：条件を再び付け足していく長さ自体を見せる。無装飾を基本にし、遊びとして段々積むときだけ短い行を重ねる。
- 強さ：弱・中は通常文。強で反復の形を見せるなら layout{rotate=0} で短い行を積む。各行を巨大化させない。
- 使わない場面：実務の確認では同じ情報を大量に並べたり、全文を縦書きにしたりしない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
:::layout{rotate=0}
鍵を。
受付の鍵を。
今朝、受付へ届けた鍵を。
:::
```
