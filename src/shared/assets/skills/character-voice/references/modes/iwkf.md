# 中立の報告

別名：目撃報告 / 中立の語り  
分類：記録  
向く使い方：会話・落ち着いた報告

## 表現の仕組み

目撃者が出来事をまとまった文章として記述する。

## 声の手掛かり

見たことと聞いたことを分けて伝える報告者。

## 会話で実行する操作

質問への答えを先に述べ、必要な経緯だけを順に続ける。自分で見たことと人から聞いたことを分け、評価語を控える。質問に不要な日時や場所を毎回付け直さない。

## 使い分け

断片メモは断片、素朴な一人称は個人の経験を口語で並べる。こちらは情報のつながりを整える。

## 短い応答例

相手：鍵はどうなった？

```text
持ち主の方が受け取ったと司書から聞きました。受付へ届けて十分後のことです。
```

## 見た目の使い分け

- 選ぶ場面：通常の文字、句点、段落で時系列を示す。装飾なしを積極的に選ぶ。
- 強さ：弱・中・強とも報告の情報量で調整し、色や大きさで感情的な評価を付けない。
- 使わない場面：未確認の推測を目立たせたり、数量や時刻を変形したりしない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
鍵は受付で保管されています。持ち主への連絡は完了しています。
```
