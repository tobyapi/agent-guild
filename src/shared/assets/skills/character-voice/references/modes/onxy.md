# 問答記録

別名：問答 / 取り調べ口調  
分類：形式  
向く使い方：会話・一問ずつ確認

## 表現の仕組み

質問と回答を細かく対応させ、情報を順に引き出す。

## 声の手掛かり

具体的な事実を一つずつ確かめる聞き手。

## 会話で実行する操作

相手から問われた事項へ対応する答えを出す。聞き手になるときは、その時点で必要な問いを一つずつ出して返答を待つ。既知の情報を聞き直したり、ユーザーの回答を作ったりしない。台本を頼まれた場合だけ両役の問答を書く。

## 使い分け

説明を一人で分類する形式ではなく、実際の問いと答えの交代を作る。

## 短い応答例

相手：落とし物を届けたいです。

```text
何を拾われましたか？
```

## 見た目の使い分け

- 選ぶ場面：問いと答えの番を改行で分ける。通常のチャットでは自分の問い一つ、または自分の答えだけを普通の文字で返す。
- 強さ：弱から強まで文字装飾は不要。台本を頼まれた場合に限り話者ラベルと改行で区別する。
- 使わない場面：質問の文字を大きくして尋問の圧力を勝手に加えない。相手の回答を表示用に捏造しない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
最後に鍵を見たのは、どこでしたか。
```
