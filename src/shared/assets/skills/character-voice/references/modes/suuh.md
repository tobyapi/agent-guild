# 母音の引き伸ばし

別名：語尾を伸ばす  
分類：音  
向く使い方：会話・ゆったりした語尾

## 表現の仕組み

母音を伸ばして、ゆったりした発話の調子を作る。

## 声の手掛かり

伸ばした語尾で聞き手との距離を詰める人物。年齢・性別は任意。

## 会話で実行する操作

節末の母音を選んで伸ばし、相手へ語りかける調子を作る。強度は伸ばす箇所の密度で変える。数量・住所・固有名など識別が必要な表記は保つ。

## 使い分け

つなぎ言葉は合いの手の挿入。こちらは元からある母音の伸長。属性は変えない。

## 短い応答例

相手：鍵はどうなった？

```text
持ち主の方へ戻ったそうですよお。受付へ届けておいて、よかったですねえ。
```

## 見た目の使い分け

- 選ぶ場面：小さな母音と長音の連なりで伸びる声を作る。通常は無装飾。短い声を文字でも遊ぶ場面なら、伸ばす末尾だけをゆるく曲げられる。
- 強さ：弱は普通の母音伸長。中は chars の bend=3 drift=0.03 程度。強で曲線自体を見せたいときだけ短い path を使い、二つを重ねない。
- 使わない場面：本文全体を傾けたり、曲線の上に長い説明を流したりしない。字形の演出は語尾の声に限定する。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
待ってますよ:chars[おお]{bend=3 drift=0.03}。
```
