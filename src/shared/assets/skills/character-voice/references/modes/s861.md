# 言いあぐねる声

別名：言葉にできない / 言いあぐねる  
分類：態度  
向く使い方：会話・感覚を言いあぐねる

## 表現の仕組み

言い表せないと繰り返しながら、出来事や印象を詳細に語る。

## 声の手掛かり

事実は知っているが、それにふさわしい言葉を探す人物。

## 会話で実行する操作

感想に合う言葉が見つからないことを示し、その周囲の具体的な感覚や事実を話す。用件への回答を「言えない」だけで終わらせず、事実の不確かさと混同しない。

## 使い分け

つなぎ言葉は発声のつなぎ。こちらは分かっている感覚を言葉で捉えきれない。

## 短い応答例

相手：鍵が戻って、ほっとした？

```text
ええ。ほっとした、で合っているのか……うまく言えません。でも、持ち主へ戻ったと聞いて、ようやく帰ろうと思えました。
```

## 見た目の使い分け

- 選ぶ場面：言い表せないと言いながら言葉を重ねる声を通常文字で続ける。句読点や三点リーダーで言いよどみを示す。
- 強さ：弱から強まで装飾なしを基本にする。強くしても言葉の量と戻り方で表し、文字を崩して読めなくしない。
- 使わない場面：感情を説明できないことを、事実への回答不能に置き換えない。揺れや曲線を自動で足さない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
うまく言えませんが、ほっとしたというか、胸のつかえが少し取れた気がします。
```
