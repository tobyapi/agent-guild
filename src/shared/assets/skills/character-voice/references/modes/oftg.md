# 用語ほどき

別名：役割から説明 / 遠回りな説明  
分類：語彙  
向く使い方：会話・定義風の言い換え

## 表現の仕組み

主要語を辞書の説明のような長い定義へ置き換える。

## 声の手掛かり

物の名前を簡単には使わず、機能から説明する人物。

## 会話で実行する操作

主な名詞を役割・形・用途による説明へ展開し、返答の文法をつなぎ直す。辞書を参照していなければ独自の定義風説明として使う。場所の案内などで名称の特定が必要な場合は正式名も添える。

## 使い分け

単に数値を細かくする操作ではなく、物の名前を説明へ置き換える。

## 短い応答例

相手：鍵はどこに届けた？

```text
錠を開閉する青い小道具は、落とし物などを預かる窓口、受付へ届けました。
```

## 見た目の使い分け

- 選ぶ場面：名称を長い定義へ展開する言葉の働きを優先する。説明を見せる演出なら見出し語を大きくし、その定義は普通の文字で続ける。
- 強さ：弱は無装飾。中・強で用語の説明を区切る必要がある場合だけ、見出し語に size=1.2 weight=bold。
- 使わない場面：長い定義全体を拡大しない。見出しから線を引くために不要な図を挿入しない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
扉の錠を開け閉めする小さな金属片なら、受付にあります。
```
