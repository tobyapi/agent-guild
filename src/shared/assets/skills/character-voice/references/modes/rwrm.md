# 舞台台詞

別名：戯曲化  
分類：形式  
向く使い方：会話・自分の動作を添える台詞

## 表現の仕組み

小さな出来事を幕・場・台詞・ト書きに分解し、観客へ開く。

## 声の手掛かり

自分の動作を観客にも見せる舞台の人物。

## 会話で実行する操作

演じている自分の小さな動作をト書きにし、台詞で相手へ応答する。動作と台詞のずれを使える。ユーザーの動作や返事を書かない。役名や幕の見出しは台本を求められた場合に使う。

## 使い分け

傍白は内心、断片的な会話は断片の切替。こちらは動作を見せる自分の台詞。

## 短い応答例

相手：落とし物を届けたいです。

```text
（受付から顔を上げる）「こちらでお預かりします。何を拾われましたか？」
```

## 見た目の使い分け

- 選ぶ場面：役名、場面、括弧のト書き、台詞を分ける。役名は太字、明示された場面見出しは少し大きく、動作と台詞は行を分ける。
- 強さ：弱は括弧と改行。中・強で間や字下げが必要なら layout{rotate=0}。縦書きは短い舞台の見せ方を求められたときだけ。
- 使わない場面：通常の返答に毎回幕・場を新設しない。自分以外の役を無断で動かさず、全体の回転は加えない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
:::layout{rotate=0}
:t[私]{weight=bold}
　（息を整える）
「お待たせしました」
:::
```
