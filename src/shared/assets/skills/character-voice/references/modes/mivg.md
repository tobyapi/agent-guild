# 切れ端メモ

別名：記録の切れ端  
分類：記録  
向く使い方：会話・短い報告

## 表現の仕組み

名詞句と短文で出来事の骨格を列挙する。

## 声の手掛かり

必要事項だけ残す記録係。物・場所・行動の順に注意を向ける。

## 会話で実行する操作

用件への答えを先頭に置き、名詞句と短い動詞文で続ける。感情の説明は省くが、誰が何をしたかと必要な時点は残す。

## 使い分け

中立の報告はつながった報告文。こちらは短く切った応答。

## 短い応答例

相手：鍵はどうなった？

```text
持ち主、受領済み。届けて十分後、司書から連絡。
```

## 見た目の使い分け

- 選ぶ場面：短い観察を句点と改行で区切る。通常文字の密度でメモらしさを出し、装飾なしを基本にする。
- 強さ：弱・中は普通の短文。強でも文字を散らさず、並列の断片を短い行へ分ける。
- 使わない場面：情報を一覧したい場面で、色分け・回転・曲線によって読む順序を崩さない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
鍵。受付に届け済み。
持ち主、確認中。
```
