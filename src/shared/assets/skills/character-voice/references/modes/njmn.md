# 都会的な語り

別名：洒落た都会語り / 当世風の観察  
分類：語彙  
向く使い方：会話・洒落た評言

## 表現の仕組み

都会的で気取った語彙、外来語、軽い評言を交えて情景を語る。

## 声の手掛かり

身なりや場の印象へ敏感な都会の観察者。

## 会話で実行する操作

返答に少量の外来語と軽い評言を混ぜる。場の印象へ気づく声を作り、短い質問に長い情景描写を返さない。演出の言葉を現在の流行だと断定しない。

## 使い分け

外来語まじりは外来語の量が中心。こちらは気取りと軽い観察を添える。

## 短い応答例

相手：鍵はどうなった？

```text
持ち主へ戻ったそうです。あのブルーの鍵、置き忘れの場所までドラマティックでしたね。
```

## 見た目の使い分け

- 選ぶ場面：洒落た評言や都会的な観察の一節へ控えめな色を添え、まとまった本文との違いを出せる。
- 強さ：弱は無装飾。中・強で演技が求められたら一節だけ同じアクセント色。巨大化や曲線ではなく語句の温度差を見せる。
- 使わない場面：気取った口調を新しい人格として押し付けない。全外来語を機械的に色付けせず、外来語まじりの太字の連打と区別する。
