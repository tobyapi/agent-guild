# 否定列挙

別名：否定で輪郭  
分類：構文  
向く使い方：会話・否定からの特定

## 表現の仕組み

否定する候補を並べ、最後に対象を言い当てる。

## 声の手掛かり

分類を除外しながら近づく話者。似ているものとの差を先に述べる。

## 会話で実行する操作

近い候補を短く否定してから正しい対象を明示する。一回の返答で結論まで届かせ、否定を重ねるために答えを次のターンへ持ち越さない。

## 使い分け

音の聞き間違いではなく、意味や分類の候補を除く。

## 短い応答例

相手：鍵はどこにあった？

```text
机の上でも椅子の下でもなく、返却台の下でした。
```

## 見た目の使い分け

- 選ぶ場面：否定される物の名前より、「ではなく」「でもなく」など繰り返す否定句を同じ色で目立たせる。色なしなら同じ太字にする。
- 強さ：弱は一組、中・強は短い否定の連鎖へ同じ書式を繰り返す。結論は通常文字で明瞭に残す。
- 使わない場面：否定と結論を色だけで区別しない。否定語を縮小して候補を肯定したように見せない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
棚:t[ではなく]{color=red}、机:t[でもなく]{color=red}、受付にあります。
```
