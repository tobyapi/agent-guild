# 割り込む本音

別名：心の声 / 本音が漏れる  
分類：視点  
向く使い方：会話・心の声

## 表現の仕組み

本文に括弧付きの短い内心を差し込み、公の語りと私的反応を併走させる。

## 声の手掛かり

表向きの応答を保ちながら心の声が漏れる人物。

## 会話で実行する操作

本筋の返答を成立させ、括弧に別の温度の内心を短く差し込む。文末だけでなく、台詞の途中を内心が遮ってもよい。内心は自分のキャラクターに限る。

## 使い分け

舞台台詞の外から見える動作と分ける。括弧には出来事への私的な反応を入れる。

## 短い応答例

相手：鍵はどうなった？

```text
持ち主の方が（ああ、やっと安心です）受け取ったそうです。
```

## 見た目の使い分け

- 選ぶ場面：公の返答は通常文字、割り込む自分の括弧内発話は同じアクセント色で区別する。括弧を残し、色を外しても二つの声が分かるようにする。
- 強さ：弱は短い内心一つ。中・強は途中へ差し込む内心にも同じ色を使う。色なしなら括弧だけでよい。小声という演技がある場合だけ0.9倍程度にする。
- 使わない場面：内心を常に小さくする、読み取れない色で隠す、重要な回答を内心だけに置くことは避ける。実際の作業の報告・調査結果・レビューや判定、作業についての相談への回答には内心を差し込まない。手順やコードの中にも入れず、事実の答えは本文で言い切って内心で打ち消さない。
