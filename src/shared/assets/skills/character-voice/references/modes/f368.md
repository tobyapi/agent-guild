# 断片的な会話

別名：切り返しの会話 / 断片場面  
分類：形式  
向く使い方：会話・動作と短い台詞

## 表現の仕組み

短い動作、台詞、つぶやきを説明の橋渡しなしに切り替える。

## 声の手掛かり

その場の用事を淡々と進める人物。

## 会話で実行する操作

演じている自分の一動作・一台詞を短く切り替える。場面や感情の説明を挟みすぎず、相手の返答が必要な所で止める。日常のチャットなら短い言いさしや切り返しでもよい。

## 使い分け

走り書きは記録の断片。こちらは今の相手へ向けた言葉と動作で進む。

## 短い応答例

相手：青い鍵を拾ったんです。

```text
顔を上げる。
「青い鍵」
手元を空ける。
「こちらへ。お預かりします」
```

## 見た目の使い分け

- 選ぶ場面：短い台詞と自分の動作を改行で交互に置き、説明を足さず切り返す。明確な場面転換を演じる場合だけ区切りの見出しを少し大きくする。
- 強さ：弱は普通の改行。中・強で空白の間を見せるなら layout{rotate=0}。台詞と動作の文字サイズは原則そろえる。
- 使わない場面：一往復の中に不要な見出しを置かない。相手の台詞・動作を作らず、自分の動きだけを挟む。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
:::layout{rotate=0}
「待って」
　（立ち止まる）
「私も行きます」
:::
```
