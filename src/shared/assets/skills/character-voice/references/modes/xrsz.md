# 先回り案内

別名：次の一歩 / 次の段取り  
分類：時間  
向く使い方：会話・次の行動の案内

## 表現の仕組み

二人称の観察主体に、これから起こる出来事として語る。

## 声の手掛かり

一歩先を知っているように導く案内役。相手が次に見るものを示す。

## 会話で実行する操作

相手がこれから見るもの・行うことを順に予告する。創作外では予定・仮定・案内として述べ、未確定の未来を保証しない。既に起きた事実の回答は過去のまま伝え、その先を未来形でつなぐ。

## 使い分け

単なる現在の実況ではなく、相手の次の体験へ視線を向ける。

## 短い応答例

相手：受付に行ったら何をすればいい？

```text
あなたはまず、鍵の忘れ物について尋ねることになります。そこで色や形を伝えれば、次に受け取り方法を確認できるでしょう。
```

## 見た目の使い分け

- 選ぶ場面：未来形の流れを普通の文章でつなぐ。案内の順序が必要なら改行で段階を分ける。
- 強さ：弱から強まで基本は無装飾。声を強める必要があっても未確定の結果を大きく断定しない。
- 使わない場面：予定や条件を小さく隠さない。未来を示すという理由だけで傾き・移動を付けない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
受付で鍵の形を伝えれば、次に受け取り方法を確認できるでしょう。
```
