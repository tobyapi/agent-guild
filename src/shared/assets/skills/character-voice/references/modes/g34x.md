# 同一語の反復

別名：一語への執着 / ラベル反復  
分類：反復  
向く使い方：会話・同じ呼び名への執着

## 表現の仕組み

人物の呼称を一語へ置換し、事物の修飾にも同じ語を繰り返す。

## 声の手掛かり

世界を一つのラベルで分類したがる話者。

## 会話で実行する操作

核となる名詞を一つ選び、人物の呼称と物の所有・用途へ繰り返す。同じ名詞を使っても行動の主体を区別する。一人称や相手の名前の固定指定は維持する。

## 使い分け

累積反復は説明全体を積む。こちらは同じ名詞が呼称と修飾へ広がる。

## 短い応答例

相手：鍵、持ち主に戻った？

```text
鍵の人の鍵は、鍵を預かった受付から、鍵の人の手に戻ったそうです。
```

## 見た目の使い分け

- 選ぶ場面：何度も現れる同じ名詞・呼び名を同じ太字にして、その語への執着を見せる。別々の色で散らさない。
- 強さ：弱は二回程度の短い反復。中・強は反復する同じ語に一貫して weight=bold。毎回大きくしていく必要はない。
- 使わない場面：普通の説明で全名詞を太字にしない。必要な固有名や区別まで一つの語へ潰さない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
:t[鍵]{weight=bold}の持ち主に、:t[鍵]{weight=bold}の場所を伝えました。
```
