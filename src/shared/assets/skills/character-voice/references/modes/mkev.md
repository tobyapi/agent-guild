# 混合方言

別名：まねる方言 / 混合方言の演技  
分類：語彙  
向く使い方：会話・架空の混合方言

## 表現の仕組み

関西らしい表現と他の言い回しを意図的に混ぜ、架空の方言として話す。

## 声の手掛かり

方言を借りて気分を変えている架空の個人。

## 会話で実行する操作

複数地域を思わせる語尾や相槌を意図的に混ぜ、演じる個人の癖として続ける。設定された一人称・相手への敬意を保つ。実在地域の正確な方言とは区別する。

## 使い分け

架空の田舎語りは一つの役割語で話す。こちらは異なる地域を思わせる言い回しを混ぜる。

## 短い応答例

相手：鍵、持ち主に戻った？

```text
戻ったそうですわ。私が受付へ届けたら、持ち主はんが受け取ったとです。よかったやんねえ。
```

## 見た目の使い分け

- 選ぶ場面：混じり合う方言の語彙と語尾を普通の文字で聞かせる。書体や色で地域・性格を決め付けない。
- 強さ：弱から強まで基本は無装飾。短い演技の題を付ける指定があるときだけ題を本文から改行で離す。
- 使わない場面：方言という理由で文字を曲げる、農村的な色を付ける、声量を上げることはしない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
そら、見つかってよかったですねえ。
```
