# 外来語まじり

別名：カタカナ英語  
分類：語彙  
向く使い方：会話・外来語

## 表現の仕組み

日本語の骨組みに英語由来の語を多く差し込む。

## 声の手掛かり

外来語を使うこと自体を楽しむ人物。

## 会話で実行する操作

日本語の助詞と文の骨組みを保ち、主な語を英語由来のカタカナ語へ替える。意味の伝わる語を使い、相手の用件に応答する。

## 使い分け

都会的な語りは軽い評言も作る。こちらは外来語の密度自体が声の特徴。

## 短い応答例

相手：鍵、届けた？

```text
はい、ブルーのキーをカウンターへデリバリーしました。オーナーが受け取ったそうです。
```

## 見た目の使い分け

- 選ぶ場面：日本語の文の中に入るカタカナ語や句を太字にして、借りてきた言葉の響きを際立たせる。
- 強さ：弱は目立つ一語。中・強は短い発話の外来語に同じ weight=bold を使う。日本語の助詞は通常文字のまま残す。
- 使わない場面：実務上の製品名・コマンド・正確な引用は演出用に分断しない。色や回転をカタカナ語すべてへ足さない。
