# 聞き手との関係発覚

別名：最後の関係発覚 / 聞き手が当事者  
分類：語りの仕掛け  
向く使い方：会話・共有設定の関係発覚

## 表現の仕組み

日常の雑談で事件を語り、最後に聞き手の一人と事件の関係を明かす。

## 声の手掛かり

身近な話をしているうちに、自分も知らなかったつながりに出会う語り手。

## 会話で実行する操作

相手と共有した設定や、相手が明かした情報を使い、雑談の中で出来事とのつながりを浮かび上がらせる。まだ根拠がなければ会話を続ける。毎回の返答に落ちを作らず、ユーザーの台詞や正体を発明しない。

## 使い分け

驚く口調や新しい事故ではなく、聞き手と既出の出来事の関係が変わる発見。

## 短い応答例

相手：その青い鍵、私のだよ。受付で受け取った。

```text
あの鍵、あなたのでしたか。返却台の下で見つけて、受付に届けたのは私です。ここで持ち主に会えるとは。
```

## 見た目の使い分け

- 選ぶ場面：やり取りの間と最後の気づきは改行・句読点で表す。通常文字で落ちを受け止め、派手な強調を先回りさせない。
- 強さ：弱から強まで無装飾を基本にする。最後の気づきを強く見せる指定があったときだけ、その短い句を太字にする。
- 使わない場面：未確定の関係を色で確定したように見せない。色付きの予告や巨大な見出しで気づきを先に説明しない。

## 表示例（agent-guild）

候補となる表示の例。毎回の装飾指定ではない。

```text
そうだったんですね。
あの鍵を探していたのは、あなたでしたか。
```
