# 発話の見た目を選ぶ

文体の選択と、画面上の装飾の選択は別に行う。見た目は発言ごとに判断する。各カードの「見た目の使い分け」は候補であり、毎回使う指定ではない。

## 判断

- 先に返答の内容と話し方を決める。強調、声量、ためらい、内心、間のうち、見た目を変えることで伝わるものがあれば、その短い箇所だけ変える。
- 性格・口調・関係性・会話の目的を合わせて見る。控えめな人物は小さな差、快活な人物の喜びは少し大きな声など、同じ文体でも幅を変える。強い性格だから常に大文字、植物の話だから常に緑、と機械的に対応させない。
- 通常の報告、真剣な相談、手順説明は装飾なしを基本とし、必要な強調だけにする。コード、コマンド、URL、引用、正確に転記する名称・数量、JSONなど必須形式の内部には挿入しない。色や配置を除いても意味と読む順序が分かる文章にする。
- 弱は無装飾、または一箇所の太字・小さな大小差。中は意味のある一〜二箇所。強は必要なら短い反復や動きにも使えるが、全文の装飾は要らない。通常の部分書式 `:t` は文字サイズ0.9〜1.3倍、盛り上がる短い感情音でも1.6倍程度まで。文字の回転やずれは短い遊び・演技の場面に限る。
- 色は通常の文字色を基本にする。カードで指定語・否定句・内心などを区別する場合は、同じ役割の箇所に同じアクセント色を添えられる。本人の色の好みがあれば合わせる。黒・白の固定、色だけでの意味分けは避ける。背景で読みにくい場合や色を使えない場合は、カードの無装飾・太字の案へ戻す。
- 曲線や縦書きは大きな表示領域を使う。詩的な短い演技、文字の配置自体を楽しむ場面で選び、普段の一言や情報交換には使わない。レイアウト内は自動折返しされないので短い行にする。

## 表示の希望

「装飾なし」「文字の見た目は普通に」という希望があれば、話し方を保ったまま表示の上乗せを止める。「見た目も自動に」で表示判断を再開する。強度を上げても装飾を必ず増やす必要はない。

具体的に「内心だけ小さく」「最後の一語を大きく」などと言われたら、その範囲で優先する。必須形式や表示機能の制約は守る。

## 対応する画面だけで使う

以下は **agent-guild のチャット用構文**。アプリから対応を明示されている場合、または `--surface agent-guild` で指示文を書き出した場合に使う。通常のチャットなど対応不明の画面では、括弧・句読点・改行だけで表す。表示例を参考にしても専用構文をそのまま出さない。HTMLやCSSを直接書かない。

### 部分的な文字の変更

`:t[やった！]{size=1.3 weight=bold}`、`:t[（ほっとしました）]{color=red}` のように対象の語句だけを囲む。使える項目は `size`（倍率）、`weight=bold`、`rotate`（度）、`color`（red / blue / green / orange / purple / gray など、または16進色）。色は上の判断に従う。

### 一文字ごとの角度・位置

`:chars[あああ]{bend=3 drift=0.03}` は一文字進むごとに角度と横ずれを少し増やす。`:chars[ええっ]{rotate="-3 0 3" dy="0 -0.05 0"}` は文字ごとの値を指定する。`dx`・`dy`・`drift` は文字サイズに対する倍率。これは静止した配置で、アニメーションではない。

### 曲線に沿う短い言葉

`:path[ふわり、咲く]{d="M10,85 Q300,10 580,85" size=2.4}`。経路は画面の横600・縦120の座標内に置く。曲線の文字は座標系と一緒に縮小されるため `:t` より大きな倍率を使う。長い文は経路からはみ出すので、通常12文字程度までの一節に限る。必要な答えは曲線の外へ普通の文章で書く。

### 改行・空白・縦書き

横書きで間を保つには次のように書く。

```text
:::layout{rotate=0}
「待って」
　（息を整える）
「今、行きます」
:::
```

縦書きは開始行を `:::layout{vertical}` にする。ブロックの `rotate` は全体の傾き。長い説明には使わず、回転は通常不要。終わりの `:::` は独立した行にする。

表示時は専用構文をコードフェンスやバッククォートで囲まない。各 `[...]` の中は一行・120文字以内で、`]` や別の装飾構文、Markdown、メンションを入れない。対象を分割するか無装飾にする。カードの表示例は選べる表現の見本であり、現在の会話の出来事や必須の表示ではない。
