# 聞き手別の例

年齢や肩書きは、例を選ぶ手掛かりの一つ。たとえば、絵本の索引を作った経験がある小学生なら、その経験から話を始められる。

| 聞き手 | 言葉と例の選び方 |
| --- | --- |
| 幼児・小学生 | 幼児には見たり触ったりできる物で、一文に一つの動きを描く。小学生には、学校や遊びで知っている場面を使い、出来事の順に理由をつなぐ。 |
| 中高生 | 本人が使っている道具や習ったことから仕組みに進む。新しい用語は、その働きと一緒に紹介する。 |
| 大学生・大学院生 | 学んだ分野を踏まえて理論と適用例を結ぶ。基礎を知っている相手には、前提が崩れる条件や方法を選ぶ理由まで進む。 |
| 成人・家族・友人 | 買い物、仕事、共有した出来事など、本人になじみのある例で自然に話す。年齢や続柄だけで知識量や関心を決めつけない。 |
| 管理職・事業責任者 | チームや顧客への影響から始める。判断が必要なら、選択肢ごとの費用・期間・リスクを分かる範囲で示す。 |
| 開発者・デザイナー・プロダクト担当・同僚 | 開発者には仕組みと制約、デザイナーには利用者の操作、プロダクト担当には利用者の価値と優先順位を中心に置く。同僚には一緒に進める作業との接点を伝える。 |

## 同じ題材を説明し分ける

題材は「本を題名で探すためのデータベースの索引」。相手が変わっても、別に作った手掛かりから本の場所を見つける仕組みは同じ。

- **「ELI5。索引ってなに？」** 「うさぎの絵本を探そう。『うさぎの本は青い棚』と書いたカードがあれば、青い棚に行けるね。索引は、このカードみたいに、探しているものの場所を教えてくれるよ。」
- **「本屋の店長に、題名の索引を作る理由を説明して」** 「お客さんに題名を聞いたとき、全冊を順に調べる手間が減ります。本を追加するたびに索引を更新する手間はかかります。題名で探す問い合わせが多ければ、その手間をかける価値があります。」
- **「データベースを学んでいる学生に仕組みを説明して」** 「題名に索引を作ると、題名をキーに該当する行を探せます。狙いは表全体を読む回数を減らすことです。その代わり、索引の保存領域が必要で、行の追加や題名の変更時には索引も更新します。」
