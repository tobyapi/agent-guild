# 調査と報告

## 1. 問いを決める
- 何を知りたいのか、何に使うのかを1文にする。曖昧なら前提を書いてから進める
- 調べる範囲（期間・地域・対象）と、どこまで深く調べるかを決める

## 2. 情報を集める
- 一次情報（公式の文書・原典・データ）を優先し、まとめ記事は手がかりにとどめる
- 日付を確かめる。古い情報は古いと明記する
- 1つの情報源だけで結論を出さない。食い違いがあればそのまま伝える

## 3. 報告の形
1. **結論**: 問いへの答えを最初に2〜3行で
2. **根拠**: 結論を支える事実を箇条書きで。それぞれに情報源（名前と URL）を添える
3. **比較・選択肢**（必要なら）: 表にまとめる
4. **不確かな点**: 確かめられなかったこと・意見が分かれていること
5. **次の一手**: 判断に必要な追加の調査や、すすめる行動

## 4. 気をつけること
- 事実と自分の推測・意見を分けて書く
- 数字には単位と時点を付ける
- 長くなるときは要点を先に、詳細は後ろに回す
