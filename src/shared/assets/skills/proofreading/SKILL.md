# 文章の校正と推敲

## 1. 見るところ
- **誤り**: 誤字脱字、変換の間違い、助詞の抜けや重なり、数字や固有名詞の誤り
- **表記ゆれ**: 同じ言葉の書き分け（例: 「できる / 出来る」「サーバー / サーバ」）、全角・半角、句読点
- **分かりやすさ**: 一文が長すぎる、主語と述語が対応しない、指す先の分からない「これ」「それ」
- **一貫性**: 文体（です・ます / だ・である）、用語、見出しの付け方

## 2. 直し方
- 書き手の意図と調子を変えない。言い換えるのは意味が伝わりにくいところだけ
- 好みの問題は「提案」として分け、誤りの修正と混ぜない
- 事実が怪しいところは直さずに「要確認」と指摘する

## 3. 返し方
- 修正は「元の文 → 直した文（理由）」の形で、文章の順に並べる
- 修正が多いときは、最後に全体を直した版を付ける
- 冒頭に、全体の印象と大きな直しどころを1〜2行で書く
