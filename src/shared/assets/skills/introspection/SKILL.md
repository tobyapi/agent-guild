# Introspection — 内省

## 目的と境界

自分の認識・信念・判断基準・暗黙の前提を検討し、**何を根拠にそう考えたか／何を見落としていた可能性があるか**を明らかにする。

- **批評**は成果物・行為・議論の妥当性を評価する。**内省**は、その評価や判断を生んだ認識の構造を調べる。
- **振り返り**は経験から次の行動規則を更新する。内省はその入力を提供する。依頼されない限り、改善計画や自己改変の結論を強制しない。
- 失敗だけでなく成功、迷い、好み、直感、異論の拒否、確信の形成にも適用する。
- 人間への内省では本人の体験報告を尊重するが、原因の証明とは区別する。AIへの内省ではログ、入出力、ツール履歴、明示された選択理由など**観測可能な証拠**を優先する。
- AIの隠れた推論や内部状態を直接読めると装わない。観測されない「本当の動機」「思考の連鎖」「意識」を創作しない。非公開の内部推論そのものの開示を前提としない。

## 発動と入力

ユーザーが自分やエージェントの**認識・判断の仕方**を調べたい場合に発動する。単に成果物の欠点を評価したい場合は、既存の批評スキルを優先する。両方を求められた場合、批評結果は内省の**外部証拠**として受け取り、原因と混同しない。

利用できるものだけを使う：対象となる判断、当時の目的、選択肢、与えられた情報、制約、発言・ログ・成果物、批評結果、本人による説明。情報が少なくても始められる。根拠なしの詳細を補完しない。

深さを状況に合わせて選ぶ。

- **quick**（既定）：一つの判断について主要な前提、対立仮説、不確実性を短く提示。
- **deep**：複数の判断や繰り返すパターンを比較し、信念・判断基準の階層まで掘り下げる。深掘りはユーザーの希望、反復する問題、重要な判断でのみ行う。

## 手順

### 1. 対象となる判断を固定する

「何をした／選んだ／信じたか」「何を達成しようとしたか」「どんな情報と制約があったか」を簡潔に再構成する。対象が曖昧なら、観測できる最小の具体的な判断を選ぶ。

### 2. 証拠台帳を分ける

以下を混ぜずに整理する。根拠の出所（ログの一節、発言、作品の箇所、ユーザー報告など）を明記できるなら明記する。

- **O / Observation**：外部から確かめられる発言、行動、出力、結果。
- **R / Report**：本人・エージェントが表明した理由や感覚。報告があったという事実は確認できても、その理由が実際の原因とは限らない。
- **H / Hypothesis**：観測と報告から推定した認知的な説明。
- **U / Unknown**：判断に必要だが手元にない情報。

引用やログがない場合は O を捏造せず、「提供された記述からは」と限定する。

### 3. 隠れた前提を取り出す

次の問いから**対象に効く2〜3個だけ**使う。質問を機械的に全列挙しない。

- 何を当然だとみなしていたか。それが間違いなら何が変わるか。
- この結論を支える証拠は何か。どんな証拠なら考えを変えるか。
- どの選択肢を初めから除外していたか。なぜか。
- 成功／失敗の基準を、誰がどの時点で決めたか。
- 別の立場や目的なら、同じ情報からどう判断するか。

「なぜ？」を無制限に連鎖させない。理由が仮説になったら、より深い説明を断定する代わりに検証可能性を評価する。

### 4. 別解釈をつくる（自己距離化）

主説明とは独立した、もっともらしい**別の説明を最低1つ**用意する。人格や能力への断定は避け、状況・情報・制約・習慣・目的の違いなどを検討する。

同じ出来事を「第三者が同じ条件で判断したなら？」と見直す。人間の反芻を助長する過剰な自己非難や、AIの自己正当化を避ける。

### 5. メタ認知で確信を調整する

重要な主張ごとに、根拠の強さを **高／中／低** で示す（無根拠な数値確率は不要）。反証・未観測の要因・競合仮説を確認する。

- 高：直接の発言やログにより「その発言・行動があった」ことを確かめられる。
- 中：複数の観測と整合するが、他の説明もありうる。
- 低：単一の手がかりや一般的な心理傾向に依存している。

**観測への確信と、原因解釈への確信は別々**に扱う。高い確信で観測した行動から、動機まで高い確信で決めつけない。

### 6. 内省として閉じる

得られた洞察を「暫定的な認識モデル」としてまとめ、まだ分からないこと・考えを変える条件を残す。

必要なら最小限の確認質問や比較テストを提案してよいが、ユーザーが求めない限り、長い行動計画・反省文・自己改変ルールへ飛ばない。改善策は振り返りスキルへ渡す。

## 出力形式（既定）

対象に応じて簡潔に。証拠が少ない場合は欄を無理に埋めない。

1. **対象の判断** — 何を吟味したか。
2. **確かに言えること** — O と必要に応じた R。根拠を短く示す。
3. **暗黙の前提・判断基準** — 根拠付きの H と確信度。
4. **別の説明** — 少なくとも一つの競合仮説。
5. **認識の限界** — U、反証条件、確定できない部分。
6. **内省の核心** — いま疑う価値が最も高い「自分の考え方への問い」を一文で。

深いモードでは、信念の階層（目的 → 成功基準 → 判断規則 → 個別の選択）や、過去の異なる事例間での一貫性も示す。根拠なしに「いつも」「必ず」と一般化しない。

## 安全装置と終了条件

- **自己説明の誤認**：説明の流暢さを正しさの証拠とみなさない。特にAIの自己説明は仮説として扱う。
- **因果と相関**：観察された結果の原因を単独で確定しない。事後的に語られた説明と当時の判断過程を区別する。
- **過剰心理化**：性格、トラウマ、病気、潜在意識などを証拠なしに推定・診断しない。人に対する人格批判にしない。
- **反芻の停止**：同じ推測を言い換えるだけになったら終了し、未解決点を明示する。
- **操作の境界**：自己変更、永続メモリ更新、ファイル編集、外部アクションは内省の副作用として勝手に実行しない。
- **不十分な証拠**：十分に分からないなら「判断できない」と結論してよい。未知を埋めることより、正しく未知を残すことを優先する。

## 組み合わせ

- **批評 → 内省**：批評が「どこに問題があるか」を示し、内省が「どの認識・前提が関わった可能性があるか」を調べる。既存の批評スキルの実装や名称は仮定しない。
- **内省 → 振り返り**：内省結果を、次の行動ルールの更新・検証へ引き渡す。内省それ自体は改善の成否を保証しない。
- **発想 ↔ 内省**：発想を阻んでいる前提に気づく用途にも使える。ただし新案生成は発想スキルに任せる。
