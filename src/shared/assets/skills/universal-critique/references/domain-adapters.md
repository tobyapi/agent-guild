# 対象別の評価軸アダプター

ここから適切な問いを2〜4個拾う。全部を適用する必要はない。どの領域でも **目的 → 観察 → 評価基準 → 解釈 → 反論 → 行動** という骨格は保つ。

## 主張・記事・議論

- 核となる主張を一文で再構成できるか。多義的な語を定義できるか。
- 前提は事実か、規範か、仮定か。結論は前提から導けるか。
- 出典の信頼性、反例、選択バイアス、基準率、因果と相関の混同を点検する。
- 最善の反対説を構築する。主張を修正すれば何が残るか。
- 最新の事実が鍵なら、アクセス可能な信頼できる一次情報で確認する。できなければ未検証と明記。

## 物語・漫画・詩・脚本

- 作品のジャンル、想定する読者体験、美学を先に見定める。
- 因果と選択、人物の欲望・葛藤・変化、展開の蓋然性、感情の準備と回収を検討する。
- 文体、視点、情報公開、コマ運び、台詞と描写、間、反復が何を作っているかを読む。
- 奇抜さ、冗長さ、曖昧さが**狙った効果**か失敗かを切り分ける。
- 観測根拠: 実際の節・台詞・ページ・時点。全文を見ていないなら断定しない。

## 美術・イラスト・デザイン・映像

- 視線誘導、階層、構図、形、色、明暗、リズム、余白、奥行き、動き・時間的変化を検討。
- 何を伝えたい画面か、対象視聴者や使用環境は何かを問う。
- 参考作品や代替レイアウトと比較し、好みと観察を区別する。
- 意図した不均衡・ノイズ・情報過多を自動的に減点しない。
- 静止画のみなら動きや音の効果を観測したと主張しない。

## 音楽・楽曲・歌詞

- 実際に音声を聴いたか、歌詞・制作プロンプトのみか、観察の入口を明示する。
- 曲構成、モチーフ、ハーモニー、リズム、音色、展開、対比、反復、歌声、意味とサウンドの関係を分析。
- ジャンルの慣習からの逸脱が意図的な魅力かを検討する。
- 音声がない場合、ミックス・グルーヴ・演奏の実態を断定せず、歌詞や仕様から論じられる範囲に限定。

## ソフトウェア・コード・AIシステム

- 仕様と実装を照合。正確性、異常系、保守性、性能、セキュリティ、UX、運用、コストの優先順位を対象に応じて決める。
- 抽象的な「悪いコード」ではなく、失敗する入力、呼び出し経路、検証方法、具体的な差分で示す。
- 実行していないテストや測っていない性能を実測結果として述べない。
- 単純な解と高度な解を比較し、複雑化する価値があるか判断する。
- 安全・機密の問題は重大度に応じて優先する。

## 企画・事業・プロダクト

- 誰の、どんな課題を、なぜこの案で解くのか。
- 代替手段、顧客行動、コスト構造、実行可能性、依存関係、取り返しのつかないリスクを検討。
- 成功指標が本来の目的の代理変数として機能するか。
- 「良さそう」から「何を試せば判断が変わるか」に落とし込む。
- 市場規模、単価、法令、競合の数字は出典なしに創作しない。

## 研究・実験・科学的仮説

- 問題設定、測定概念、対照群、再現性、内的妥当性、外的妥当性を検討。
- 交絡、選択、後付け仮説、多重比較、サンプルサイズ、分布外への一般化を確認。
- 可能なら代替仮説と、それを区別する実験を提案。
- 専門家の合意が必要な論点はその限界を明示する。

## 制度・倫理・社会・歴史

- 事実主張と「そうあるべき」という規範主張を分ける。
- 誰が得をし、誰が負担するか。効率・自由・公平・安全などの価値はどう衝突するか。
- 当事者ごとに最も強い解釈を作り、歴史的起源と正当化の根拠を混同しない。
- 法律、医療、安全、政策の実務判断は専門的・最新の根拠の確認が必要。断定や誘導を避ける。

## 個人の意思決定や行動

- 当人の目標、制約、時間軸、価値観を勝手に置き換えない。
- 現状維持、代替案、可逆性、機会費用、不確実性を比較する。
- 人格や属性を評価するのでなく、検討対象の行動・理由・結果を扱う。

## 評価基準そのものの批評

最も重要なのに見落とされやすい三つの問い:

1. その基準を満たすことと、本来の目的を達成することは本当に同じか（代理指標の罠）？
2. その基準で優れた対象を評価すると、どんな独創性や少数者の価値を見落とすか？
3. 同じ対象を別の正当な価値観で評価したら、結論は変わるか？
