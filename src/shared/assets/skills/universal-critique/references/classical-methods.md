# 古典的な批評の道具箱

この表は思想家の議論をAI向けに**実務化した応用**であり、各思想家が現代のAIレビュー手順をそのまま提唱したという意味ではない。著作年代・用語には翻訳差がある。適切な方法を1〜3個選ぶ。権威の名前で結論を正当化しない。

| 方法 / 代表者 | 使う場面 | 実行する問い | 誤用を避ける |
| --- | --- | --- | --- |
| エレンコス / ソクラテス（紀元前5世紀） | 「良い」「成功」等の定義が曖昧・自己矛盾 | 用語を定義し、その定義と両立しない合意済みの前提を探す | 対話から矛盾が出ても唯一の正解が得られたとは限らない |
| 三表の法 / 墨家（戦国期） | 公共的主張・政策・実用性 | 過去の模範・経験的証拠・運用上の利害を検討する | 古代の歴史的権威を現代にそのまま妥当な根拠として輸入しない |
| 目的・構成の分析 / アリストテレス（紀元前4世紀） | 作品、設計、行動、仕組み | 何のための対象か。各部分は全体の働きにどう貢献するか。物語なら出来事の必然性・蓋然性は？ | 『詩学』は悲劇など固有の媒体を論じたもの。すべての作品に同じ悲劇の規範を強制しない |
| イドラの吟味 / F. ベーコン（1620） | 判断が先入観・流行・用語に左右されそう | 人間共通の偏り、個人の癖、言葉による混乱、既存学説への依存はないか | 「バイアスがある」だけでは結論の誤りを証明しない |
| 趣味の標準 / D. ヒューム（1757） | 美学・味・作品の良し悪し | 経験と比較の幅、感受性、先入観の少なさは足りているか | 美的評価を実験事実と同一視しない。熟達者の見解も絶対ではない |
| 一致法・差異法 / J. S. ミル（1843） | 因果関係、比較実験、性能検証 | 成功例と失敗例で変わった条件は何か。交絡を排除できるか | 観察上の一致だけで因果が確定したとは言わない |
| 系譜学 / F. ニーチェ（1887） | 価値基準・慣習・制度・常識 | その基準はどう成立し、誰の欲望・利害・歴史と結びついたか | ある価値の起源を示すだけでその価値は偽と結論しない |
| 反省的探究 / J. デューイ（1910〜） | 問題解決・製品改善・仮説検討 | 漠然とした違和感を問題に定式化し、仮説・予測・行動・検証へ進める | 手順を固定した順番の儀式にせず、必要に応じて問題設定を戻す |
| 精読 / I. A. リチャーズ（1929） | 文章、脚本、詩、画面上の情報 | 作者の肩書きや説明を脇に置き、実際に現れている語や構造だけから何が言えるか | 文脈や作者情報を永久に無視するという意味ではない |
| 比較形式分析 / H. ヴェルフリン（1915） | 絵、映像、構図、視覚UI | 線／絵画的、平面／奥行き、閉／開、複数性／統一性、明瞭性の相違を比較する | 5対の分類は序列や万能の良し悪し判定ではない |
| 反証可能性 / K. ポパー（1934） | 科学的・経験的な予測と理論 | どんな観測なら主張が誤りだと判断するか | 単一の不一致には測定誤差・補助仮説がある。価値判断に無理に適用しない |

## 最短の選択ルール

- **主張の曖昧さ**: ソクラテス → ベーコン
- **真偽と因果**: 墨家の経験的基準 → ミル → ポパー
- **ストーリー・設計の構造**: アリストテレス → リチャーズ
- **美的評価**: ヒューム → ヴェルフリン（視覚表現の場合）
- **暗黙の価値や制度**: ソクラテス → ニーチェ
- **改善と実験**: デューイ → ミル
