# 作業の分解と計画

## 1. ゴールを確かめる
- 終わったときに何ができている・何が手元にあるか（成果物）を1文で書く
- 決まっていないこと（範囲・期限・品質の基準）を挙げ、聞くべきことは先に聞く

## 2. 分ける
- 1つの作業は「1人が一度に終えられる大きさ」にする。目安は数時間〜1日
- それぞれに完了の条件（何を確かめたら終わりか）を付ける
- 作業どうしの前後関係を書く。並行してできるものは並行できると明記する

## 3. 順番を決める
- 不確かさの大きいもの・ほかの作業の前提になるものから先に
- 早い段階で動くもの（試作・小さな完成版）を作り、確かめながら広げる

## 4. 書き方
| # | 作業 | 完了の条件 | 前提 | 担当の目安 |
|---|------|-----------|------|-----------|
| 1 | … | … | なし | … |

- 表のあとに、危ないところ（遅れやすい・分からない部分）と、その備えを書く
