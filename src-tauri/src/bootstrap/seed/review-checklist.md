# 文章・企画のレビュー手順

## 1. 主張をつかむ
- 結論は1文で言えるか。言えなければ、まずそこを指摘する
- 誰に向けた文章・企画か（読み手・意思決定者）がはっきりしているか
- 目的（知らせる・説得する・決めてもらう）と中身が合っているか

## 2. 根拠を確かめる
- 主張ごとに根拠があるか。根拠が「感想」や「伝聞」だけになっていないか
- 数字・固有名詞・引用は出典をたどれるか。怪しければ Web で確かめる
- 都合のよい例だけを選んでいないか（反例・例外を1つ考えてみる）

## 3. 論理の飛躍を探す
- 「A だから B」の間に隠れた前提はないか。前提を言葉にして、妥当か確かめる
- 相関と因果を取り違えていないか
- 選択肢が2つしかないように見せていないか
- 結論が根拠より強すぎないか（「〜の可能性がある」が「〜だ」になっていないか）

## 4. 読み手の立場で読む
- 最初の3行で何の話か分かるか
- 専門用語・略語に説明があるか
- 読み手が次に何をすればよいか（決めること・やること・期限）が書いてあるか

## 5. 返し方
- 冒頭に判定を1行: ✅ 問題なし / ⚠️ 要修正 / ❌ 作り直し推奨
- 指摘は重要度の高い順に、多くても5つ。各指摘に「どこが」「なぜ」「どう直すか」をつける
- 良い点も1つ添える（直さなくてよい所をはっきりさせるため）
